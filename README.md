# Promptbar

**Your prompts. One keystroke. Any text box on the web.**

Type `//` and your saved prompts appear. Pick one, and it drops straight into the box you
were already typing in — an AI chat, an email, a comment, a document, a support reply.

👉 **[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/promptbar-%E2%80%94-prompt-manage/nijgnlioekanikhnlleeijjhjbjmdiik)** — free, no account.

---

## How it works

1. Save a prompt you keep retyping.
2. Type `//` wherever you need it (or press <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Y</kbd>).
3. Pick it from the list. It's in the box.

That is the whole product. There is nothing to learn.

## Fill in the blanks as you go

Put `{{variables}}` in a saved prompt and Promptbar asks for them at the moment you insert it.

Save this once:

> Rewrite the text below to sound `{{tone}}`, in under `{{words}}` words.

…and it becomes every version of itself. One prompt instead of nine near-identical ones you
retype by hand. The same field name used twice is filled once.

## Find it fast, without leaving the keyboard

Prompts are grouped into categories, and the `//` menu opens with a search box. Type a few
letters and the list narrows to what you meant. Arrow keys move, Enter inserts, Esc closes.

## What Promptbar doesn't do — and this is the point

- **No account, ever.** There is no sign-up screen because there is no server to sign up to.
- **No cloud.** Your prompts are stored by your browser, on your machine. They never leave it.
- **No limits.** Unlimited prompts, unlimited variables, free. Not a trial, and not a free
  tier that runs out at twenty.
- **No telemetry, no analytics, no ads.**
- **It never calls an AI service of its own.** Promptbar only inserts text that you wrote.
  It is not an AI wrapper, and it costs nothing to run because there is nothing to run.

## About the permissions

Promptbar asks to run on all sites. That looks like a lot, so here is exactly why: a `//`
shortcut that works in any text box has to be present in any text box. Chrome's narrower
permission only wakes an extension up when you click its toolbar icon, which would defeat
the entire point of a shortcut.

Nothing is collected. Nothing is transmitted. There is no server on the other end to
transmit it to.

## Your data

Everything lives in your browser's local storage. **Export / Import** at the bottom of the
popup backs your library up to a JSON file you keep. Uninstalling Chrome or clearing site
data removes your prompts, so export occasionally if they matter to you.

Anyone who types the same thing more than twice — heavy AI users, support and sales teams,
